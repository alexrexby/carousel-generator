# 🎠 Carousel Generator (Конструктор каруселей)

Универсальный модульный генератор карточек для Instagram / соцсетей на базе Python и Pillow.
Генерирует слайды высокого разрешения **1080x1350 px (4:5)** с адаптивной версткой, правильной типографикой (привязка предлогов, союзов и чисел неразрывными пробелами), поддержкой мягких теней, размытий и автоматическим созданием контакт-листов для проверки глазами.

---

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```
*(Требуется только библиотека `Pillow`)*.

### 2. Запуск генерации

```bash
# Список всех доступных каруселей
python run.py list

# Список доступных тем оформления
python run.py themes

# Собрать конкретную карусель из встроенной базы
python run.py render voda

# Собрать все карусели из базы
python run.py render --all

# Собрать карусель из своего JSON-файла с темой по умолчанию
python run.py render --json decks/sample_deck.json --theme default

# Собрать карусель с темной темой
python run.py render --json decks/sample_deck.json --theme dark --out output/my_dark_deck
```

Результаты сохраняются в папку `output/` (карточки `01.png`, `02.png` ... + единый контакт-лист `preview.png` со всеми слайдами).

## 🎨 Темы оформления (Themes)

Темы хранятся в папке `config/*.json`. Каждая тема задает:
* Никнейм / хендл для футера (`handle`)
* Цветовую палитру: `primary`, `primary_dark`, `primary_soft`, `ink`, `gray`, `line`, `white`
* Фотографию по умолчанию (`default_photo`)

### Предустановленные темы:
1. `amalia` — фирменный стиль Амалии Саргсян (акцентный синий, глубокий индиго, мягкий голубой, белый).
2. `default` — современная универсальная тема (индиго/фиолетовый, сланец, белый).
3. `dark` — контрастный темный режим (изумруд, графит, глубокий фон).

Чтобы создать свою тему, просто добавьте `config/my_theme.json`:
```json
{
  "name": "my_brand",
  "handle": "@my_brand",
  "colors": {
    "primary": [255, 75, 75],
    "primary_dark": [200, 50, 50],
    "primary_deep": [140, 30, 30],
    "primary_night": [50, 10, 10],
    "primary_soft": [255, 235, 235],
    "primary_tint": [255, 248, 248],
    "ink": [20, 20, 25],
    "gray": [110, 115, 125],
    "gray_light": [170, 175, 185],
    "line": [235, 240, 245],
    "white": [255, 255, 255]
  },
  "default_photo": "photo.jpg"
}
```

## 📄 Формат слайдов (JSON Schema)

Каждая карусель — это список слайдов 4 типов:

### 1. `cover` (Обложка)
Белый слайд с крупным заголовком и цветным акцентом.
```json
{
  "type": "cover",
  "title": [["Собрания", "INK"], ["«по нужде»", "PRIMARY"], ["- это уже поздно", "INK"]],
  "lead": "Когда вы наконец решаете всех собрать, спасать обычно уже нечего."
}
```

### 2. `break` (Перебивка)
Цветной градиентный слайд с глубоким свечением (размытые сферы).
```json
{
  "type": "break",
  "tag": "Проблема",
  "bignum": "3-4",
  "title": [["месяца проблема живёт в бизнесе", "WHITE"]],
  "lead": "А команда узнаёт о ней только в последний день.",
  "quote": "Собрание - это не тушение пожара. Это профилактика."
}
```

### 3. `list` (Чек-лист / Список)
Слайд для сохранения. Поддерживает нумерацию (`"numbered": true`) или стильные галочки.
```json
{
  "type": "list",
  "tag": "Раздел 1",
  "title": [["О чём говорить", "INK"], ["на собрании", "PRIMARY"]],
  "label": "Разбираем каждый раз:",
  "numbered": true,
  "items": [
    "Отзывы клиентов за месяц",
    "Ошибки - разбираем ситуации, а не людей",
    "Что происходит с планами и налогами"
  ],
  "quote": "Без регулярных собраний любая система в бизнесе обнуляется."
}
```

### 4. `cta` (Финальный слайд / Кодовое слово)
Слайд с фото эксперта, растушевкой и плашкой с кодовым словом.
```json
{
  "type": "cta",
  "tag": "Забирайте",
  "title": [["Разбираю это", "INK"], ["голосом в канале", "PRIMARY"]],
  "lead": "Там же всё остальное про команду и регламенты.",
  "word": "СОБРАНИЕ",
  "photo": "photo.jpg"
}
```

```

├── README.md               # Документация проекта
```

## 🛡 Принципы верстки
* **Никаких висячих предлогов:** автоматический перенос союзов, предлогов и тире через неразрывные пробелы.
* **Авто-расчет высоты:** отступы, кегли шрифтов и межстрочные интервалы вычисляются алгоритмически, карточки не ломаются от длинных текстов.
* **Контакт-лист `preview.png`:** после каждой сборки собирается сетка всех слайдов, чтобы перед публикацией оценить весь визуальный ряд одним взглядом.
